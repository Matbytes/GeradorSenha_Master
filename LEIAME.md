Gerador de senha com integração ao excel

Projeito feito por Matheus Oliveira da Silva

Linguagem: Python

Instruções:

-Clone este repositorio

-Entre na pasta do projeto e crie uma ambiente virtual (python -m venv nomeAmbienteVirtual)

-Ative o ambiente virtual:

    -Entre na pasta do ambiente virtual que você criou:

    Windows:

    source /PastaAmbienteVirutalCriada/bin/activate.ps1 ou .bat

    Linux ou MacOS:
    
    source /PastaAmbienteVirtualCriada/bin/activate

    Vai depender mais do shell que você estiver usando

-Instale as dependencias necessárias:

    python -m pip install -r requirements.txt

Após isso, só executar o projeto

-A senha estará salva em um arquivo spreadsheet chamado de "senhas.xlsx"

-Não se esqueça de salvar a planilha!!!!!

OBS:. Podera ver alguns bugs por conta de que sou novato e é meu primeiro projeto sério. Caso encontre um, não hesite em deixar nos comentarios

Password generator integrated with Excel

Project made by Matheus Oliveira da Silva

Language Python

Instructions

-Clone this repo

-Open this project folder and make a virtual environment (python -m venv nameVirtualEnvironment)

-Activate the virtual environmnet:
    
    Windows:
    
    source /VirtualEnvironment/bin/activate.ps1 or .bat

    Linux or MacOS:

    source /VirtualEnvironment/bin/activate

    It will depend more on the shell you are using

-Install the necessary dependencies:

    python -m pip install -r requirements.txt

After that, run the project

-The password will be saved on the spreadsheet file "senhas.xlsx"
